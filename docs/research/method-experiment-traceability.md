# Method-Experiment Traceability

> 用途：把 contribution、方法模块、实验、表图和允许声称串成闭环。它是 paper 侧与 proposal traceability 对应的资产。

## 一、Traceability table

| Contribution | Method module | Experiment | Table / Figure | Allowed claim | Evidence status |
|---|---|---|---|---|---|
|  |  |  |  |  | planned / real / missing |

## 二、Checks

- [ ] 每个 contribution 都映射到至少一个 experiment 或 limitation note
- [ ] 没有实验支持的 claim 已降级或移除
- [ ] 主要表图都有对应正文段落
